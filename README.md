# AWS Learning Labs

Repositorio personal donde documento mi aprendizaje práctico en AWS, laboratorios realizados y preparación para la certificación AWS Solutions Architect Associate (SAA-C03).

---

## Sobre este repositorio

El objetivo es construir experiencia práctica mediante laboratorios reales, documentando paso a paso cada implementación y los conocimientos adquiridos durante el proceso.

Cada laboratorio incluye:

- Objetivo
- Arquitectura
- Procedimiento
- Capturas de evidencia
- Conceptos aprendidos
- Notas para el examen AWS SAA-C03
